This project will predict, 30 minutes in advance, how many bikes will be available at each Valenbisi station. Valenbisi is Valencia's public bicycle service, and it provides an open public API. It will also publish the accuracy for each day.

** DATA ** 
API used: https://docs.citybik.es/api/v2
